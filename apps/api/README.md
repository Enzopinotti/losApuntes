# API

Historical NestJS API source rescued from branch `backend` at `51b67bb71c4ec03d9b94963fc139695140c5563d`.

The rescued API still reflects the old Mongo/Mongoose implementation and JWT-only authentication. Both are legacy behavior under review, not accepted 2026 architecture.

Physical MongoDB data, `node_modules` and the historical Mongo docker-compose state were deliberately excluded.
