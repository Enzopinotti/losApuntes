## Findings and dependency paths

The production audit reached two patched advisories through the Mobile/Expo and Web toolchains:

- `react-native@0.86.3 -> react-devtools-core@6.1.5 -> shell-quote@1.10.0`. `react-devtools-core@6.1.5` declares `shell-quote ^1.6.1`; no later `6.x` release is available in the registry. The root override `react-devtools-core>shell-quote: 1.11.0` scopes the fix to that parent and keeps the Expo/React Native versions unchanged. GitHub marks `shell-quote@1.11.0` as patched for [GHSA-pqg4-j6r4-53mv](https://github.com/advisories/GHSA-pqg4-j6r4-53mv).
- `postcss@8.5.28 -> source-map-js@1.2.1` and `sass@1.104.1 -> source-map-js@1.2.1`. Their declared ranges accept `source-map-js@1.2.2`; parent upgrades would expand the dependency change without improving the fix. Root overrides scoped to `postcss` and `sass` resolve the patched version. GitHub marks `source-map-js@1.2.2` as patched for [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q).

The override policy lives in the root manifest and is materialized by pnpm in `pnpm-lock.yaml`. The lockfile was regenerated by the repository-pinned pnpm version; it was not edited manually.
